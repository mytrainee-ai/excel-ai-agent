# Excel AI Agent

Учебное приложение для работы с заявками техподдержки через чат, OpenAI Responses API и существующий Excel MCP Server.

Страница Streamlit показывает таблицу заявок и чат. Схема приложения описана в [ARCHITECTURE.md](ARCHITECTURE.md), требования — в [PRD.md](PRD.md).

Учебная таблица вмещает до 1000 заявок в строках 2–1001 листа «Заявки».

## Подготовка на Windows

Нужны Python 3.12 и существующий Excel MCP Server с собственным окружением. Путь к интерпретатору сервера указан в `.env.example`.

В PowerShell из корня проекта выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path -LiteralPath .env)) { Copy-Item .env.example .env }
```

Укажите в `.env` значения `OPENAI_API_KEY` и `OPENAI_MODEL`. Для чата нужна модель с поддержкой вызова функций и Structured Outputs в Responses API. Сверьте `MCP_PYTHON_PATH` с расположением существующего сервера. Шаблон содержит остальные значения для учебной книги. [Документация OpenAI о структурированных ответах](https://developers.openai.com/api/docs/guides/structured-outputs)

## Инициализация учебной книги

```powershell
.\.venv\Scripts\python.exe -m scripts.init_excel
```

Команда использует настройки Excel и MCP из `.env` или окружения процесса. Ключ и модель OpenAI для неё не нужны. Команда создаёт `data/requests.xlsx` с листом `Заявки` и записями №101–103. Повторный запуск сохраняет существующий файл.

Для восстановления учебных данных используется отдельная команда:

```powershell
.\.venv\Scripts\python.exe -m scripts.reset_excel
```

Она покажет путь к книге и имя листа. Введите `СБРОС`, чтобы заменить данные на листе «Заявки» исходными тремя записями. Любой другой ответ отменяет операцию. Сброс сохраняет остальные листы книги.

## Запуск

```powershell
.\start.bat
```

Скрипт запускает приложение на `127.0.0.1`. Адрес появится в терминале. Для остановки нажмите `Ctrl+C` в том же терминале.

Ручной запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

В PyCharm выберите интерпретатор `.venv\Scripts\python.exe` из этого проекта. Создайте конфигурацию Python с типом запуска **Module name**, модулем `streamlit`, параметрами `run app.py --server.address 127.0.0.1` и рабочим каталогом в корне проекта.

## Учебная демонстрация

На исходных заявках №101–103 выполните три запроса:

1. «Добавь заявку от Анны Смирновой: ноутбук сильно тормозит.» В таблице появится заявка №104 со статусом «Новый».
2. «Измени её статус на „В работе“.» Сверьте ID, описание, текущий и будущий статусы. Нажмите «Подтвердить». Если данные изменились за время ожидания, приложение покажет обновлённое предложение.
3. «Покажи все заявки со статусом „В работе“.» В чате и таблице появятся №103 и №104. «Обновить» перечитывает книгу и сохраняет фильтр, «Показать все» его сбрасывает.

В боковой панели «Журнал MCP» раскройте операцию, чтобы увидеть порядок вызовов, аргументы, результаты и длительность. В записи смены статуса видны подготовка и итог. Отказы контроллера отмечены с причиной. Чат и журнал хранятся в текущей сессии Streamlit.

## Диагностика запуска

- Если `start.bat` сообщает об отсутствии Python или модулей, создайте окружение проекта и установите зависимости из `requirements.txt`.
- Если проверка сообщает об отсутствующей настройке, проверьте соответствующее поле в `.env`. При ошибке связи с MCP проверьте `MCP_PYTHON_PATH` и установку сервера в его окружении.
- Если книга отсутствует, запустите `python -m scripts.init_excel` из окружения проекта. При ошибке записи проверьте доступность книги и закройте её в Excel, если она заблокирована.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pytest
```

Для тестов ключ OpenAI не нужен. Ответы OpenAI подставляются через тестовый HTTP-транспорт SDK. Интеграционные тесты используют `MCP_PYTHON_PATH` из окружения процесса или путь из `.env.example` и создают отдельные книги во временном каталоге pytest. Если интерпретатор сервера отсутствует, эти тесты пропускаются.

Сквозная приёмка с реальной моделью запускается отдельно. Она использует настройки OpenAI и отдельную временную книгу:

```powershell
$env:EXCEL_AGENT_LIVE_TEST = "1"
.\.venv\Scripts\python.exe -m pytest -q -s tests/test_scenarios.py
Remove-Item Env:EXCEL_AGENT_LIVE_TEST
```
